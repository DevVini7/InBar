# InBar
O Inbar não mostra apenas lugares — ele mostra experiências acontecendo em tempo real.

## Iniciar o projeto
Abra `index.html` na raiz do repositório, de preferência com o Live Server do VS Code. O fluxo começa no login de teste; após entrar, usuários sem preferências salvas passam pelo onboarding de interesses antes de chegar à HOME em `Tela_home/index.html`.
